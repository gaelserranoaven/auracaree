# AuraCare v3.4 - Features & Release Notes

> **Documento histórico.** Describe la v3.4 (agosto de 2026), anterior al backend. La versión vigente es la **v4.0** (Supabase Auth, Postgres con RLS, Realtime), en piloto desde el 2026-09-28. La referencia actual es [`ARCHITECTURE.md`](../../ARCHITECTURE.md) y [`docs/OPERACION.md`](../OPERACION.md). Las "limitaciones" y "siguientes pasos" de abajo ya no aplican.

**Release Date:** 2026-08-17  
**Status:** Histórico (reemplazado por v4.0)

## Overview

AuraCare v3.4 is the latest version of the elderly care management platform, featuring a refined UI/UX and improved data handling.

## Key Features

- Responsive care dashboard
- Patient profile management
- Daily activity logging
- Medication tracking
- Staff scheduling interface
- Real-time notifications (UI ready)

## Changes vs v3.3.1

- Improved navigation structure
- Enhanced CSS styling for better accessibility
- Optimized layout for larger screens
- Better form validation UI
- Refined color scheme

## Known Limitations

- Local storage only (no backend sync)
- No persistent data (reloads lose changes)
- Single-user interface (no multi-user support)

## Next Steps (v3.5+)

- Backend API integration (Node.js/Express)
- Database persistence (PostgreSQL)
- Real authentication system
- Multi-user support
- Mobile responsive design
